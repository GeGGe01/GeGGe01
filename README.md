### What I'm building

**[Flashbackaren](https://github.com/GeGGe01/flashbackaren-public)**

A product development project that also serves as an experimental environment for exploring AI-assisted software engineering.

One outcome is **PoaG**, an experimental approach to reducing communication errors and unnecessary complexity in human–AI development workflows.

The methodology emphasizes goal-oriented delegation, lightweight specifications, meaningful human oversight, and short feedback loops.

My early observations are promising, but I'm particularly interested in whether the approach can be generalized beyond my own environment.
